Null-calibrated data mining · Python

Your miner always finds something. Is any of it real?

Ghost Patterns reruns your exact mining pipeline on copies of the data with the structure shuffled away, then keeps only the findings that beat what the noise produced.

The problem

Mining algorithms cannot return nothing.

Apriori

Rules from shuffled data

Lower the support threshold far enough and pure noise yields rules with lift above 1. More columns, more rules.

k-means

Clusters from static

Ask for k clusters and you get k clusters, with a respectable silhouette, from a featureless Gaussian blob.

Isolation Forest

Anomalies on quota

Set contamination=0.05 and exactly 5% of points are flagged, in 2 dimensions or 200, real outliers or none.

So "the algorithm found patterns" is not a result. A pattern becomes a result when it beats what the same pipeline finds in data that has no pattern. Everything below that bar is a ghost.

What it does

Five checks between mining and a claim.

Leakage

Catch rules true by construction

Functional dependencies, duplicate encodings, sorted rows and arithmetic totals, found before mining.

Calibration

Beat the strongest ghost

Family-wise and false-discovery-rate tests against eight null models, each matched to a kind of data.

Attribution

Find the load-bearing columns

Shuffle one column at a time to see where the structure lives and which columns are decoration.

Highlights

Measured on data where the answer is known.

Use it

One command, one shareable report.

Command line

Analyse a CSV, ask what predicts one column, and open the report.

pip install .
ghostpatterns analyse mushrooms.csv \
    --target Mushroom_quality --open

Python library

The same engine the command uses, returning plain data.

from ghostpatterns.analyse import Options, analyse, save

result = analyse(df, Options(target="label", n_null=100))
print(result.headline())
save(result, "results/mydata")
