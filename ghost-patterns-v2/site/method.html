Method

Five steps, in an order that matters.

Deduplicating after calibration corrects for thousands of copies of one finding. Skipping the leakage check validates your own preprocessing. The package fixes the order.

The pipeline

  1. Check for leakage

    On raw data, before mining.

  2. Mine, focused on one question

    Apriori; optionally only rules that predict a target column.

  3. Remove padded copies

    A sampling-error threshold, applied before any correction.

  4. Run the same pipeline on matched noise

    One of eight null models, chosen for the data type.

  5. Calibrate every finding

    Family-wise and false-discovery-rate tests against the null.

1 · Leakage

Leakage produces dependence that is genuinely present, so it passes every statistical test. It must be caught separately. Each detector looks for one signature of structure the analyst created.

DetectorSignatureMeasure
Functional dependencyOne column determines anotherU(B|A) ≥ 0.999
Near-determinismAlmost determinesU ≥ 0.95
Duplicate encodingTwo names for one variableU in both directions ≥ 0.95
Row orderingValues sorted across columns≥ 95% of rows monotone over a window of ≥ 3 columns
Arithmetic derivationA total or a differenceColumn equals a ± b
Strong associationAdvisory onlyNormalised mutual information ≥ 0.15

U is the uncertainty coefficient, the fraction of B's entropy explained by A:

U(B | A) = 1 − H(B | A) / H(B)
Run it on raw data. Binning launders leakage: it weakens the signatures the detectors look for without weakening the spurious rules. The advisory tier exists for data that has already been transformed.

2 · Mining

Each categorical column becomes items column=value. Columns with more than 15 distinct values are left out, because high-cardinality columns are a major source of ghosts. Apriori finds itemsets above minimum support; each split into antecedent A and consequent C gives a rule.

confidence = s(A ∪ C) / s(A)    lift = confidence / s(C)

Target focus. Name a target column and only rules with a single target item as consequent are tested, and the null is filtered the same way. This replaces thousands of arbitrary hypotheses with the question you are asking.

3 · Redundancy

If {A}→{C} is real, {A, X}→{C} scores well for almost any irrelevant X. Worse, adding a condition subsamples the data, so lift becomes noisier and the best padded child usually beats its parent by chance. A fixed tolerance lets those children through. The margin must scale with sampling error:

keep child r only if lift(r) > lift(parent) + z · lift(parent) / √count(r), z = 1.96

This runs before calibration, so the multiple-comparison correction applies to distinct findings only. In the planted-signal experiment it reduced 451 mined rules to 166 distinct ones.

4 · Null models

A null model destroys exactly the structure being claimed and keeps everything else. Keep too little and real findings look falsely impressive; keep too much and they look falsely weak.

The null is a modelling decision. On basket data with no real affinity, column shuffling let 292 of 442 rules through; swap randomization let none through. Report which null you used and why.

5 · Calibration

The identical pipeline runs on R null replicates. Two distributions are kept: every null lift (L) and the best lift of each run (M). For a real rule with lift ℓ:

p = (#{x ∈ L : x ≥ ℓ} + 1) / (|L| + 1)    pFWER = (#{x ∈ M : x ≥ ℓ} + 1) / (R + 1)

Per-rule p-values are corrected with Benjamini–Hochberg to give q-values. The +1 in each fraction keeps p above zero: a finite null can never justify certainty.

The replicate guard

With R null runs, the smallest attainable p-value is 1/(R+1). If that is above α, the test can never reject, and it reports its own inability as "nothing found".

Rmin = ⌈1/α⌉ − 1   → 19 runs for α = 0.05, 99 for α = 0.01

This was a real bug during development: a cluster test with 10 runs reported two perfectly separated blobs as noise. Every empirical p-value in the package now passes through the guard. Try the "Too few null runs" preset in the lab.

Column attribution

Count the strong rules, then shuffle one column at a time and count again. The drop shows where the structure lives. Columns with no significant drop are decoration and can be removed without losing anything.

Clusters

  • Calibrated silhouette. Real silhouette minus the silhouette k-means reaches on matched Gaussian noise. The excess is the evidence, not the raw score.
  • Gap statistic. Dispersion against a uniform reference; smallest k with gap(k) ≥ gap(k+1) − s(k+1).
  • Stability. Adjusted Rand index across 80% subsamples, compared with noise, because k-means on a blob is not perfectly unstable either.

Anomalies

The null's 99th-percentile score sets the threshold, so 1% of null points exceed it by construction. Only an observed rate well above 1% is evidence. Relative contrast, (farthest − nearest) / nearest, is reported first: below 0.3, distances have collapsed and distance-based detectors measure nothing.
