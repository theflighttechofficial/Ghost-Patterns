Limits

  • Per-rule p-values compare a rule with all null rules, not with the same itemset's null distribution.
  • No correction across k in clustering, so one k beat noise on pure noise (p = 0.048).
  • Benchmarks used small trial counts; the FDR estimate is explicitly inconclusive.
  • A null model shows that structure exists, not that it matters in the domain.
